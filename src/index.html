About the Addon

This addon serves one managed IPTV snapshot into Stremio. Normal users only need the secret code, while admins can refresh the source snapshot from a local sync tool.

  • Secret-code install flow
  • One managed Supabase snapshot
  • Email allowlist plus server-side cooldown for sync
  • Channel, Movie & Series catalogs
  • Local + Redis caching support
