How It Works

  • The hosted addon always reads from one managed Supabase snapshot.
  • Users only need the secret code to install the addon in Stremio.
  • Admins sign in with Supabase only when they want to download the sync tool and overwrite the snapshot.
  • The downloaded sync HTML fetches the Xtream panel locally and uploads a full overwrite to Supabase.
  • Refresh is enforced server-side with a rolling 30-minute cooldown.
